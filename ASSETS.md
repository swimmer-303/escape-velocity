# Escape Velocity: Asset Credits

> **Update (Nov 14, 2026):** the Space Apps organizer confirmed that a disclosure at the start of the slides and at the bottom of the website is enough, so the shipped images no longer carry a per-image watermark. They were re-processed from the same originals with the same steps, minus the watermark (`scripts/process-art.py` and `scripts/process-portraits.py` take `--watermark` to add it back). Disclosure now lives in the title screen footer, the in-game Credits, the README and the pitch deck's first slide.

All images and music in this game were made with AI. This page lists every shipped file, the tool and model used, the exact prompt, and what we did to it afterwards.

- **Images:** every image in `public/art/` was generated with **Higgsfield** using the **GPT Image 2.6** model (`gpt_image_2_6`, quality `high`, resolution `1k`, aspect ratio 16:9). The title image was made first. It was then given to the model as a style reference for all the other images so the set looks consistent. Each shipped image has a visible **"AI-generated"** watermark baked into the bottom-right corner by `scripts/process-art.py`. The crew portrait sheets (`public/art/crew-*.png`, see [Crew portraits](#crew-portraits)) use the same model and title reference, are processed by `scripts/process-portraits.py`, and carry an **"AI"** tag on every portrait plus a full **"AI-generated"** label along the bottom of each sheet.
- **Audio:** every file in `public/audio/` was generated with **Higgsfield** using the **ElevenLabs Music v2.5** model (`elevenlabs_music_v2_5`, `force_instrumental: true`). The audio is credited here and in each MP3's ID3 tags (title, artist and comment).
- **No logos, flags or insignia:** no NASA logos (meatball or worm), no flags of any country, and no mission patches, insignia, agency names or brand marks were used in any prompt or appear in any output. Every image prompt says "No logos, no flags, no text, no insignia, no lettering." We checked each image by eye before shipping it.
- **Originals:** the full-resolution originals (1344x752) are not in the repo. The shipped files are downscaled, retro-processed versions.

## Shared style text

Every image prompt below ends with this exact style text. It is written out in full in each row too.

> Style: retro 1990s low-poly 3D video game render, PlayStation 1 style, chunky flat-shaded polygons, simple textures, charming miniature diorama, warm palette: rust red #7a2e17, oxide orange #c2562a, butterscotch Mars sky #d9a066, pale dust #ecc98f, with accents of cyan #5ef2e6 and amber #ffb627; Mars sunsets are blue #5b7bb5. Cute, friendly, kid-appropriate. No logos, no flags, no text, no insignia, no lettering.

## Images

Saved as optimized 8-bit PNG. Short form in the table: "downscaled, palette-quantized, AI-generated watermark baked in".

## Crew portraits

The 15 astronauts (4 + 5 + 6, listed in `src/data/crew.ts`) are fictional: made-up first names, no real people and no real astronauts' likenesses. Each crew's portraits were generated as one image: a grid of square portrait panels, one face per panel, in roster order.

- **Tool / model:** Higgsfield, GPT Image 2.6 (`gpt_image_2_6`), quality `high`, resolution `1k`. Crew 1 at 1:1 (1024x1024, a 2x2 grid); crews 2 and 3 at 3:2 (1024x688, 3x2 grids).
- **Prompts:** these end with a portrait version of the shared style text (character portraits instead of a diorama, plus "no patches, no name tags"). It is written out in full in each row.
- **Style reference:** `public/art/title.png`, cropped to its left 536x360 pixels so its watermark (and any lettering) was not in the reference.
- **Watermark approach:** a full "AI-generated" label does not fit legibly on a single portrait that is shown about 100 pixels wide. So each crew is one sprite sheet: every portrait has a legible **"AI"** tag (white Silkscreen pixel font on a navy box) baked into its bottom-right corner, and the sheet has a full-width navy strip along the bottom with **"AI-generated"** in the same font. The game shows one cell of the sheet per astronaut, so the "AI" tag is on screen with every face, and the intro also says "Crew portraits are AI-generated art."
- **Post-processing (all three sheets):** `scripts/process-portraits.py` finds the dark grid lines, crops each panel to a square (90% of the panel, framing the face), downscales it with LANCZOS to 96x96, palette-quantizes the crew's portraits together to 40 colors (median cut with k-means refinement, no dithering), upscales 2x with nearest-neighbor to 192x192 per portrait, lays them out left to right, bakes in the "AI" tags and the "AI-generated" strip (32 px), and saves an optimized 8-bit PNG (12 to 19 KB each). Short form in the table: "cropped to portraits, downscaled, palette-quantized, AI tag + AI-generated strip baked in".
- **Checked by eye:** all three results were read at full size before processing. None show logos, flags, insignia, patches, name tags or lettering (the robot's face and the gadget screen have no text). Nothing had to be regenerated.
